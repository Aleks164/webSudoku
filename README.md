# Web Sudoku

Современная веб-версия игры Судоку, разработанная с использованием React и TypeScript.

## Особенности

- Адаптивный дизайн с фокусом на мобильные устройства
- Высокая производительность
- Минималистичный и приятный интерфейс
- Автоматическое развертывание через GitHub Actions

## Технологии

- React 18
- TypeScript
- Vite
- CSS Modules

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
